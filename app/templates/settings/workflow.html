Рабочие процессы

Настройте передачу обращений между основными ролями и автоматическую эскалацию по времени.

Как проходит обращение
  1. Новое обращение клиента поступает в очередь роли первого уровня.
  2. Сотрудник может передать его только по настроенному направлению.
  3. Маршрут по умолчанию может автоматически передать обращение после заданного времени ожидания.
  4. После передачи обращение переходит в очередь целевой роли без прежнего ответственного.

Статусы и допустимые переходы между ними остаются доменными правилами приложения. На этой странице настраиваются именно переходы между очередями.
