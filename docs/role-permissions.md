# Управление разрешениями ролей

## Интерфейс

1. Откройте «Настройки» → «Роли».
2. Раскройте пользовательскую основную роль.
3. Выберите «Разрешения».
4. Отметьте нужные действия в группах «Клиенты», «Сотрудники», «Роли и доступ», «Диалоги» и «Настройки».
5. Сохраните изменения.

В списке показываются название, описание и код каждого разрешения. Разрешения, которыми текущий сотрудник не обладает, нельзя добавить через интерфейс. Если такое разрешение уже было назначено роли ранее, его можно отозвать.

## Ограничения безопасности

- Страница доступна сотрудникам с разрешением `roles.assign_permissions`.
- Изменять разрешения системных ролей, включая администратора, нельзя.
- Специальные роли «Начальник», «HR» и «Глобальный HR» имеют фиксированный набор разрешений и не редактируются как обычные роли.
- Сервер повторно проверяет каждое изменение. Подмена формы или прямой POST-запрос не позволяют выдать разрешение, которого нет у самого сотрудника.
- Сотрудник может отозвать ранее выданное разрешение, даже если сам больше им не обладает.
- Каталог разрешений формируется централизованно в `app/core/permissions.py`; системные роли и их стандартные разрешения синхронизируются при инициализации RBAC.

## Специальные роли

В карточке основной роли отображаются специальные возможности:
- «Начальник — ...» — просмотр информации и уведомлений в пределах основной роли.
- «HR — ...» — управление составом только соответствующей основной роли.
- «Глобальный HR» — управление составом всех основных ролей.

Набор разрешений специальных ролей задается серверной логикой RBAC, а не пользовательской формой.
