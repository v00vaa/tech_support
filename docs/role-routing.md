# Маршрутизация диалогов между ролями

## Основные понятия

- Основная роль — рабочая очередь, например «Поддержка — уровень 1».
- Исходящее направление — разрешенная передача из исходной роли в целевую.
- Входящее направление — список исходных ролей, которые могут передать диалог в текущую.
- Маршрут по умолчанию — направление, используемое для автоматической передачи.
- Время автопередачи — число минут ожидания диалога без назначенного сотрудника в очереди исходной роли.

Специальные роли «Начальник» и «HR», а также роль администратора не могут выступать исходными или целевыми ролями маршрутизации.

## Настройка

1. Откройте «Настройки» → «Роли».
2. Раскройте основную роль.
3. Откройте «Направляют к».
4. Выберите целевую основную роль.
5. При необходимости отметьте «Маршрут по умолчанию» и укажите время автопередачи в минутах.
6. Сохраните направление.

Для одной исходной роли разрешен только один маршрут по умолчанию. Повторное сохранение той же пары ролей обновляет существующую запись. Удаление маршрута немедленно запрещает новые передачи по нему.

Раздел «Получают от» показывает входящие направления и доступен только пользователям с правом просмотра ролей или настройки маршрутизации.

## Передача диалога

В карточке диалога отображается текущая очередь. Пользователь с разрешением `dialogs.route_to_role` может передать диалог только в роль, доступную по исходящим направлениям текущей очереди. Если очередь еще не назначена, можно выбрать любую активную основную роль, кроме администратора.

При ручной передаче ответственный сотрудник снимается, очередь меняется, а время ожидания начинается заново.

## Автоматическая передача

Автопередача выполняется для диалогов, которые:
- находятся в очереди исходной роли;
- не имеют назначенного сотрудника;
- имеют статус, отличный от «Ожидание клиента», «Решен» и «Закрыт»;
- ожидают не меньше заданного числа минут.

После передачи очередь меняется на целевую, а время ожидания сбрасывается. Если целевая роль также имеет маршрут по умолчанию с тайм-аутом, диалог может быть передан дальше при следующем цикле worker.

Чтобы запустить worker постоянно:

```powershell
flask --app app run-auto-forward-worker --interval 60
```

Параметр задает интервал проверки в секундах (минимум 5). Для production worker должен запускаться отдельным управляемым процессом и перезапускаться службой управления процессами. Его не следует запускать внутри каждого web-worker процесса.

Однократная проверка очередей:

```powershell
flask --app app process-auto-forwards
```

## Разрешения

- `roles.manage_routing` — настройка и удаление направлений между ролями.
- `dialogs.route_to_role` — ручная передача диалога в доступную роль.

По умолчанию право настройки маршрутизации выдается администратору, а право передачи диалогов включено в базовую роль поддержки.
